# VENTAS WALMART
Base de datos para el analisis del comportamiento de ventas por departamento a travez del tiempo, considerando las caracteristicas del producto y el departamento de venta. Analisis realizado usando Google Sheets

**PREGUNTAS A RESPONDER:**

* ¿Qué categorías de departamento fueron más eficientes para generar ventas en 2012?
* KPI 1: Ventas por metro cuadrado (eficiencia): Ventas / Tamaño.
* ¿Qué departamentos aportaron más al negocio y cuáles estuvieron por debajo de su potencial?

**Proceso a grandes pasos:**
* LIMPIAR: preparar los datasets para su análisis.
* ENRIQUECER: unir tablas en una sola fuente integrada.
* RESUMIR: crear tablas dinámicas con los KPIs.
* DASHBOARD: diseñar un dashboard con filtros y visualizaciones.
* RESUMEN: redactar un informe C-F-I.
* QA: documentar validaciones de calidad y un README.
